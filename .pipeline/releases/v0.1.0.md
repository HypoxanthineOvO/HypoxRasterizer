# Release v0.1.0

发布时间：2026-04-28 16:03（上海时间）

## Summary

Prepared the first HypoxRasterizer validation/research release. This release
packages the renderer improvements, validation scenes, Python visualization
toolchain, and experimental IndirectVPL support delivered through M1-M20.

## Included

- V2 scene config, CLI, and structured output contract.
- Float G-Buffer, depth, shadow, and VPL debug outputs.
- Directional lights, point cube shadow maps, and area direct VPL sampling.
- Validation suite manifest, fast/standard/heavy tiers, external asset hooks,
  output baselines, and tolerance comparison tools.
- uv-managed Python 2D/3D visualization and reporting tools.
- Experimental first-bounce IndirectVPL sampling, shading integration, debug
  buffers, and Cornell/Money/Dragon validation entries.
